# Pagination audit (P3, 2026-10-05)

Rule (CLAUDE.md): lists page by cursor, never by offset. "Bounded" means a hard
`limit` with no way to reach older rows. Checked by reading each route and its
repository query; "fixed" rows changed in `build/p3-documents`.

| Surface                                                 | Endpoint                                     | Before P3                                                                    | Now                                                                                                                                     |
| ------------------------------------------------------- | -------------------------------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Documents, uploaded                                     | `GET /v1/documents`                          | Unbounded (every document, every version row)                                | **Fixed.** `?limit&cursor`: keyset (updated_at, id), active only, opaque `nextCursor`; index `documents_owner_active_updated_idx`       |
| Documents, made by Q                                    | `GET /v1/q/artifacts`                        | Cursor (`before`, `nextBefore`), but the page read only the first 50         | **Fixed in the page:** both sources paged and merged without reordering ("Show more"); tie-break index `artifacts_owner_updated_id_idx` |
| Notifications                                           | `GET /v1/notifications`                      | Bounded: newest 30, older ones unreachable                                   | **Fixed.** `?before=` keyset (created_at, id), `nextBefore`; bell has "Show older"; index `notifications_user_created_id_idx`           |
| Results                                                 | `GET /v1/results`                            | Windowed by date range; rows capped (pipeline 200, history 100, meetings 50) | Unchanged: a report over a chosen range, the CSV/PDF export carries it. Follow-up: say when a section is capped                         |
| Relationships                                           | `GET /v1/network/*/relationships`            | Bounded: newest 200                                                          | Unchanged. Follow-up: keyset by (created_at, id) when an organisation nears 200                                                         |
| Work done                                               | `GET /v1/q/work/done`                        | Cursor + limit                                                               | Already cursor                                                                                                                          |
| Usage                                                   | `GET /v1/q/usage`                            | One month's totals (aggregate, no rows)                                      | Not a list                                                                                                                              |
| Admin queues (accounts, organisations, reviews, safety) | `GET /v1/admin/*`                            | Bounded: 25-50 newest, search narrows                                        | Unchanged (operators only, search-first). Follow-up: cursor on reviews if the queue grows                                               |
| Discover                                                | `GET /v1/discovery/*`                        | Cursor (slates)                                                              | Already cursor                                                                                                                          |
| Chat messages                                           | `GET /v1/network/relationships/:id/messages` | `after` + `limit` cursor                                                     | Already cursor                                                                                                                          |
| Q conversations / events                                | `GET /v1/q/conversations`, events            | Cursor                                                                       | Already cursor                                                                                                                          |
| Search                                                  | `/search` page                               | Bounded per tab, name match                                                  | Unchanged: a search result, refined by the query                                                                                        |

Not fixed here and why: Results, Relationships and Admin are bounded, not
unbounded; each is listed as a follow-up so the cap is never silent.
