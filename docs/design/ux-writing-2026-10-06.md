# UX writing pass, 2026-10-06 (H1/H2)

Audit of user-visible strings in `apps/web` for non-technical founders and
investors. Most screens had already been rewritten in plain words; this pass
removes the system words that were left. GateQ, gateway, `app/dev` and the
operator admin console were out of scope. Truth labels, legal text, consent
text and what each action does are unchanged.

## Kept on purpose

- Product terms the founder chose: Q, Discover, Explore, GateQ, Company
  requests, Connection Request, Work, Q Daily, Board, Data room, Pitch deck,
  mandate, hard rules, Q's view, fit scores.
- Truth labels (Verified, the company's own claim, Estimate, Q's inference,
  Unknown) and evidence wording.
- "Not virus-scanned yet". ADR 0042 §5 quotes this exact label. "Not yet
  checked for viruses" is plainer, but changing it needs an ADR 0042 note
  first.
- The operator admin console (`/admin`), which only Capital Q staff see.
