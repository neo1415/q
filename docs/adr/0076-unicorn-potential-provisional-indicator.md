# ADR0076: Separate provisional Unicorn Potential indicator

Status: Accepted within owner direction,17October2026.

Unicorn Potential is a deterministic, versioned assessment of present evidence against the owner-approved12-pillar/24-criterion methodology. Its0–100 signal is separate from Investability and investor-specific Suitability. It is not a probability or validated forecast of a billion-dollar outcome; PADL forecast/uncertainty boundaries remain.

Stage weights, coverage gates, self-report limits, confidence and one-time rounding follow `docs/product-sources/unicorn-potential/research-methodology-v1-2026-10-17.md`. Numerical weights are provisional product assumptions rather than statistically estimated coefficients. Unknown is never zero. Method changes require a new version and historical reproducibility.

Use only investor-universally-eligible canonical evidence; private or relationship-only sources cannot alter this signal. Persist append-only snapshots and reauthorize current source eligibility and premium account access on every API/Q/filter read. No browser-only entitlement or cross-reader score cache. A revoked source withholds the current assessment until a new legitimate snapshot exists.

Explicit premium Discover sorting/filtering may act only on already eligible candidates; existing default fit-order.v2 and InvestIQ arithmetic are unchanged. Founder improvements remain within founder permissions. Public Q Cards must not carry premium payloads.

Demo access uses explicit audited billing feature overrides for verified existing accounts, without altering base plans, ranking or email-domain authorization. No new provider/model call computes or displays a score.
