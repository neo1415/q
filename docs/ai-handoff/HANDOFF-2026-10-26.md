## 3. Release lane (exactly how a change reaches production)

1. Merge the PR head SHA into local `speed/q-oct20` (`git fetch origin <sha>;
git merge FETCH_HEAD`). Union-merge test files on conflict; otherwise ask the
   PR owner to rebase.
2. Gate locally; **count errors, never trust `&& echo ok`**:
   - `pnpm exec turbo run build --filter=./packages/*` (stale `dist` gives false
     failures — this caught us twice on 10-26);
   - `node --max-old-space-size=7168 node_modules/typescript/bin/tsc --noEmit -p tsconfig.json`
     and the same inside each touched app; `grep -c 'error TS'` must be 0;
   - `NODE_OPTIONS=--max-old-space-size=8192 pnpm exec eslint <changed files>`
     (it OOMs without the heap flag);
   - `pnpm exec prettier --check <changed files>`;
   - `pnpm exec vitest run <touched apps/packages>` from the repo root (running
     from inside an app finds no files).
3. `git push origin HEAD:refs/heads/recovery/2026-09-12-8y2j4w` (CI ~25 min).
   Do not push again while a run is going unless you mean to cancel it.
   - pgTAP sometimes fails at "Start the local database" (runner port 54322 in
     use). That is infrastructure; re-run the failed job once.
4. Migrations only: after pgTAP is green,
   `SUPABASE_ACCESS_TOKEN=… NODE_USE_ENV_PROXY=1 node scripts/handoff/hosted-migrate-https.mjs --apply <version>`
   (note: `scripts/handoff/`, not `scripts/handoff/live/`).
5. Deploy: `git push origin <sha>:refs/heads/recovery/2026-09-12` and the same
   SHA to `build/int-rc`.
6. Wait for all four services: `node scripts/handoff/live/railway/deploys.mjs`.
   A builder that FAILS with an empty deploy log is a Railway flake: redeploy the
   same SHA with `railway/deploysha.mjs <service> <full sha>`.
7. Run the regression guard from the **deployed** commit's files (see §5), then
   ask each lane to verify its fix live.

## 9. Lessons from this weekend (why it went in circles)

- Regressions shipped because unit tests passed while the live guard did not
  cover the case (F-106 broke via #529's router change; the guard then caught
  it). Add the guard case **with** the fix, and keep its timing bound.
- A guard case that accepted any card list let a slow, wrong path count as a
  pass (I-top-five). Make expectations specific.
- Probes that open a new conversation per prompt measure the wrong thing;
  carry the conversation.
- Batching many PRs per deploy saved CI time but made attribution slower; ship
  risky changes (routing, reader, disclosure) on their own.
- Define the finish line first (§2) and stop when it is met.
