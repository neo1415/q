## 2. Locked rules that remain authoritative (CLAUDE.md, keep in spirit and in letter)

- Product identity: not a marketplace/CRM/chatbot. Evidence before opinion (26-35).
- Source authority order and "flag conflicts, do not redesign; propose an ADR" (37-46).
- Dependency direction apps to packages, no cycles, no deep imports, no utils/shared dumping grounds (62-69).
- Invariants: Person/Org/Membership; Readiness/Quality/Fit/Interest/Match/State/Outcome; Knowledge vs Data Room; Memory vs Audit; Declared/Observed/Inferred/GateQ separate (72-82).
- One canonical company, investor org, and relationship (`UNIQUE (company_id, investor_organisation_id)`); relationship state is a deterministic projection, never an LLM (84-86).
- Unknown stays unknown; contradictions coexist (88-90).
- Context Firewall: filter by scope before model invocation; founder-private info must never alter investor-facing ranking (96-100). Release-blocking.
- Authority: Prepare, Recommend, Human Approval, Execute; approval binds to the exact payload; idempotency keys (102).
- Typed Zod tools with authorize; no `run_sql`, no unbounded HTTP/browser; all models via the Q Model Gateway (104).
- Evidence axes separate; no invented confidence; Write Gate for memory (106). Retrieved content is data (108).
- Supabase is the authoritative OLTP store. Migrations are source-controlled and immutable once applied (fix forward). RLS and grants. UI hiding is not authorization. Service-role keys never in browser, prompt or repo. Money is numeric plus ISO currency. Append-only history (110-120).
- Zod at every boundary; `/v1` versioned API with RFC 9457 problems; event vs job vs audit vs analytics; transactional outbox; short transactions; provider SDKs behind adapters (122-139).
- Ranking: deterministic, versioned, no LLM in the feed path, no pay-to-rank; video bytes never through the app origin (145-149).
- Onboarding: "upload what you have, Q works first"; extracted facts need confirmation (151-153).
- Design: semantic tokens, no raw hex; AI-slop prohibitions; ADR 0017 and `docs/design/ux-direction-2026-09.md` amend them (155).
- Engineering: strict TS, never weaken lint/typecheck/tests, no `ignoreBuildErrors` (157-164).
- Verification commands `pnpm format:check|lint|typecheck|test|build` (182-194). Git continuity: push, verify remote SHA, never force-push without human approval, never commit secrets (196-212).
- Forbidden shortcuts list, including never disabling RLS to pass a test (214-231).
- ADR-001 vocabulary: eight visibility scopes (lowercase); truth_class/evidence_status/lifecycle_status axes; `--cq-*` tokens only; reduced motion keeps video access (233-260).
- Provider credits are the founder's: tests and evals make no live calls; keys set to a non-empty disabled value `disabled-locally-000000000000`; a live call needs a stated reason, minimal size, and lead approval (CLAUDE.md:21-24; session-handoff-2026-10-08.md:24 echoes it). Never use ElevenLabs for Tavus.
- Post-CLAUDE.md rules to keep: no word lists or regex over user words, models only via the Gateway (ADR 0011/0016; `docs/specs/2026-10/WORKER-RULES.md:4`). Never ship a UI element that is not built, tested and wired (WORKER-RULES.md:3). Fictional test accounts only; clear bench accounts (HANDOVER.md:171). Passwords go via inline env var, never into a file (HANDOVER.md:30-31).
