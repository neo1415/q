# Any language — registry, machine-translated screens, provider capability (2026-10-16)

Lane `lang`, branch `claude/lang-oct16`. Owner direction (2026-10-16): the requirement is a **language setting** — a person picks any supported language and switches between any two — not an English/Arabic toggle. Owner change of plan the same day: **no hand catalogues for further languages and no per-language code**; screens in any language come from machine translation of the English catalogue through the Model Gateway, cached and shared. Arabic (lane ml, `MULTILINGUAL-2026-10-16.md`) stays as the one hand catalogue and wins wherever it has a string.

## Machine translation (UI_TRANSLATION)

- **Task class:** `UI_TRANSLATION` (contracts and the migration).
- **Routing:** `ui_translation.v1` sends PUBLIC material to `gpt-5.6-luna`, falling back to `gemini-3.5-flash-lite`. Luna is the cheapest active capable model ($0.20 in, $1.20 out per M tokens).
- **Budget:** each batch has `maxEstimatedCostUsd` 0.05.
- **Source:** `packages/q-core/src/ui-text/source.generated.ts` holds 4,051 English strings, which are the web hand-catalogue keys plus the email keys. Regenerate it with `node --experimental-strip-types scripts/i18n/generate-ui-text-source.mts`. A web test fails if the file is stale, or if a `t("…")` literal is missing from it.
- **Only the source is translated.** A client names a language, never text.
- **Checks** (`checkUiTranslation`, in q-core):
  - Every `{placeholder}` must come back exactly, the same multiset.
  - Every digit run and ISO currency code must survive (the codes come from `Intl.supportedValuesOf("currency")`).
  - Product names and a lone Q must survive.
  - A result that is empty or too long is refused.
  - A refused string is stored as `REJECTED` with its reason code. It shows in English and is never paid for again under the same version.
- **Cache:** `q_runtime.ui_translations` is keyed by (language, `catalog_version` `ui-text.v1`, SHA-256 of the English, computed by the database). It is non-tenant, server-only, RLS on with no policies, and anon and authenticated are revoked. pgTAP suite 973 covers it.
- **Serving:** `GET /v1/q/ui-text/:language`.
  - The route needs an authenticated actor.
  - It returns what is cached and starts one single-flight background fill per language (2 batches in flight, 60 strings each).
  - The web keeps a process-wide cache: 10 minutes for a complete language, 15 seconds while one is filling.
  - Until a language is filled, the screens show English. Once filled, it is instant for everyone.
- **Spend cap:** the class has its own daily ceiling, `CQ_UI_TRANSLATION_DAILY_CAP_USD`, USD 2 unless set. It is a plain number from 0 to 50; anything else fails at startup. It sums `ai_ops.model_usage` rows of this task class only.
  - When the cap is reached, the fill stops and the DTO says `paused: "DAILY_BUDGET"`. English stays.
  - The gateway's global daily cap still applies on top.
- **Estimated cost of one full language** (4,051 strings, 68 batches, about 66k input tokens): about USD 0.07 for a Latin-script language and USD 0.10 for others on luna, or USD 0.14–0.21 if it all fell back to flash-lite. At USD 2 a day that is roughly 10–25 new languages a day. **Not measured live:** no live translation call was made by this lane.
- **Deploy order:** ship the code first, then apply `20261228150500_ui_translations.sql`. Older catalog loaders reject a routing policy with an unknown task class. The loader on this branch now skips unknown classes, so this cannot recur.

**Honest fallbacks:**

- **Voice:** if the person chose a language that Deepgram cannot hear or ElevenLabs cannot speak (Swahili, Yoruba, Hausa …), opening a standard voice line returns 422: "Q can't hold a voice conversation in Swahili yet … Type to Q instead and Q answers in Swahili". A device language nobody chose is only a hint, and the line opens.
- **Video:**
  - Rehearsal video in a language Tavus does not list returns `VOICE_FALLBACK` / `LANGUAGE_UNAVAILABLE`, and no paid room is claimed.
  - A GateQ room in such a language runs in English, with an English disclosure, and the entry page says so before anyone starts.
- **Settings:** shows the same facts per language.

**Only a human can verify:**

- naturalness of each voice and face per language;
- dialect comprehension;
- the quality of machine-translated screens in each language (Q's checks guard the structure, not the wording).
