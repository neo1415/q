## Shared cause of today's gate restarts (point 2)

Six of today's full-gate failures were catchable in under five minutes: unformatted handoff docs (twice), a missing Arabic string, a migration version collision, stale tests beside changed code, and lint on changed files. The common cause: commits reached the 26-minute gate without the cheap subset of its own checks. `scripts/pre-gate.sh` runs that subset on files changed since production (prettier, unique migration versions, catalogue with 0 gaps, package build, eslint, root tsc, `vitest related`); the gate runs only after it prints `pre-gate PASS`. Workers run it before their final push. The OOM/contention failures had a separate shared cause (concurrent heavy commands), handled by the gate-idle rule.
