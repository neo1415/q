## What went wrong, and the fix (workstream V)

| Finding                                                                  | Cause                                                                                                                                                                                                   | Fix                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "Give me three good examples" was marked FAILED after 23–30 s            | The line's 30 s delegation deadline aborted the run. The nudges ("still waiting…") arrived as new delegations, and the voice turn handler superseded (cancelled) the run in flight.                     | The broker queues delegations per line, so a newer one never cancels the one running. The runaway deadline is now 90 s, and its message never says "in time". After about 5 s the voice is told once to say, in a few specific words, what it is getting. A result that lands after a newer request is still spoken while that newer request is pending; it is never dropped. |
| Dead air after "Right." (twice)                                          | The prompt allowed a bare acknowledgement.                                                                                                                                                              | The prompt now requires every acknowledgement to be followed by substance, and a nudge to be answered with what is coming. A nudge is never re-delegated.                                                                                                                                                                                                                     |
| "No, I'm not gonna do that" when asked to laugh                          | The prompt said "never laugh".                                                                                                                                                                          | Q now laughs naturally and lightly when asked, or when something is genuinely funny, and never refuses rudely.                                                                                                                                                                                                                                                                |
| "Tensorgate" heard as "Tensorflow"                                       | The session had no names.                                                                                                                                                                               | The session instructions carry the person's own record names, remembered terms and relationship counterparts.                                                                                                                                                                                                                                                                 |
| Garbled opening ("They thanked you and said the rest is on your screen") | The briefing card copy was paraphrased line by line.                                                                                                                                                    | The opening is now driven by the app: a greeting, then the briefing summarised (how much is waiting, the top two or three items by name, what each needs). Q is told never to read card or screen text.                                                                                                                                                                       |
| A superseded run stuck in CANCEL_REQUESTED (run 07:30:23)                | The voice turn handler cancels the run it was waiting on when a new turn starts (`turn.ts` `supersede` → `qRuntime.cancelRun`). The run then stayed CANCEL_REQUESTED, which is the runtime's to finish. | The line no longer triggers that path: it queues instead of superseding. The runtime staying in CANCEL_REQUESTED is reported to B.                                                                                                                                                                                                                                            |
| Ended at 183 s                                                           | The 3-minute cap.                                                                                                                                                                                       | The cap is now 20 minutes by default and at most 60 (`CQ_VOICE_LIVE_MAX_SESSION_SECONDS`). The line closes after 3 minutes of no speech either way (`CQ_VOICE_LIVE_IDLE_SECONDS`). The daily spend cap is also checked mid-call, on every usage report.                                                                                                                       |
