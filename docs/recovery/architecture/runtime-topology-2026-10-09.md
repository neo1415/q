## 6. Recommendation

**Option A now, and measure again before considering C. Reject B.**

- Biggest wins are config-only and free: web in `sfo` costs ~162 ms per call and roughly doubles the browser RTT for EU users. Move web to `europe-west4` and route web→api/q-api over `*.railway.internal`.
- Next in size are code fixes, the same on any host: stream Q deltas (#1/#2), batch the run's 605 round trips and the nav/profile/explore reads (#3), and lengthen the pool idle timeout (#5).
- C buys ~7–8 ms per remaining DB round trip. Worth revisiting only if, after A, the per-request `dbRoundTrips` (now logged) stays high on hot paths. B costs boundary and security rework for ≤5 ms once A lands.
