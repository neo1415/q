# SongScribe AI — investor deck

- **PDF:** [`songscribe-investor-deck.pdf`](songscribe-investor-deck.pdf) — 20 slides, 1280×720 px, 0.48 MB, text selectable.
- **Source:** [`songscribe-investor-deck.html`](songscribe-investor-deck.html), generated by `scripts/seed/flagship/deck/build.mjs songscribe` (offline; Chromium print).
- **Facts:** only from [`../research.md`](../research.md), [`../facts.json`](../facts.json) and [`../brand.json`](../brand.json). Statuses: VERIFIED_PUBLIC · SELF_REPORTED · OWNER_PROVIDED · ASSUMPTION · UNKNOWN. Unknown stays unknown; it is never shown as zero.
- **Design direction:** Dark cinematic SongScribe brand (#0A0A0A, red #E63946/#DC2B3C, maroon #7F1D1D, amber #F59E0B; Inter Display heavy headlines, Geist Mono labels). Narrative device: an album — Side A "the song" (product), Side B "the business", then "liner notes & credits". A tracklist strip on every slide shows position; the market and next-steps slides are full red "singles"; the title uses a square red record sleeve. Visually distinct from KUUZA's two-column investor-call layout.

## Brand use

- Colours from `brand.json` (site HTML and compiled CSS). Space Grotesk (brand display font, itself an ASSUMPTION in brand.json) is not available offline, so headlines use Inter Display; Geist Mono is the OFL file in `scripts/seed/flagship/deck/fonts/`.
- No logo file used: the site publishes no asset licence ('All rights reserved'). The wordmark is typographic — SONG in red, SCRIBE in white — matching the logo's split colouring without the S glyph. Logo source recorded in brand.json: https://www.songscribe.ai/images/songscribe-logo.png.
- No photography or sample cover art: samples contain real people's names.
