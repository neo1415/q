# Zino Aviation — investor deck

- **PDF:** [`zino-aviation-investor-deck.pdf`](zino-aviation-investor-deck.pdf) — 21 slides, 1280×720 px, 0.42 MB, text selectable.
- **Source:** [`zino-aviation-investor-deck.html`](zino-aviation-investor-deck.html), generated by `scripts/seed/flagship/deck/build.mjs zino-aviation` (offline; Chromium print).
- **Facts:** only from [`../research.md`](../research.md), [`../facts.json`](../facts.json) and [`../brand.json`](../brand.json). Statuses: VERIFIED_PUBLIC · SELF_REPORTED · OWNER_PROVIDED · ASSUMPTION · UNKNOWN. Unknown stays unknown; it is never shown as zero.
- **Design direction:** Zino Aviation Jet's editorial palette (cream #F6F4EF, gold #B59B48 / #D9C48A / #8A7434, charcoal #222222 / #141414, line #E7E2D6) with a serif display face and geometric sans. Narrative device: a flight plan — each slide is a numbered leg, with a waypoint route bar along the bottom from Departure to Arrival; title, market and funding slides are charcoal "night" legs. Services carry the research's operating status (Active / Marketed / Planned / Partner-delivered) as well as evidence status.

## Brand use

- Colours from `brand.json` (jet.zinoaviation.com css :root). GT Alpina (commercial) and Poppins/Cormorant Garamond are not available offline, so display type is Crimson Pro and UI type is Outfit (both OFL, in `scripts/seed/flagship/deck/fonts/`).
- No logo file used: no public brand licence was found, so the deck uses a typographic "ZINO AVIATION" wordmark. Official logo source recorded in brand.json: https://jet.zinoaviation.com/assets/img/logo-gold.svg.
- No photography: Jet imagery is Unsplash (third-party photographers) or company-owned without a licence.

- Revenue, enrolments, placements, funding: UNKNOWN.
- Unnamed airline agreements and the 'As Featured in' logo strip: not presented as partnerships or coverage.

- Marketing superlatives ('world's first and leading', 'state-of-the-art', 'youngest commercial pilot'): attributed and marked unverified, never asserted.
- Founder date of birth from the register: deliberately omitted.
